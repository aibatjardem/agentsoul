## Особый режим: этот проект — AgentSoul (dogfood)

**Это не обычный консьюмер soul-комплекта. Это сам soul-комплект.**

Источник истины — `core/`. Файлы `.soul/identity.md`, `.soul/agents.md`, `.soul/README.md`, `.claude/agents/*`, `.claude/skills/*` в корне репозитория — **результат установки** `core/` в сам AgentSoul. Они генерируются командой `npm run dogfood` (`agentsoul update` по этому репозиторию) и коммитятся вместе с изменениями в `core/`.

Правила:

1. **Не редактируй управляемые файлы в корне напрямую.** Правь `core/soul/*`, `core/skills/*`, `core/agents/*`, затем `npm run dogfood`. Ручная правка в корне — это drift, `npm run check` его покажет.
2. **`.soul/stack.md` и `.soul/glossary.md` в корне — реальные данные AgentSoul о себе**, не шаблоны. Шаблоны живут в `core/profiles/*/stack.md` и `core/seed/glossary.md` и не должны содержать реальных данных.
3. **После любого изменения `core/` или `src/`:** `npm test` и `npm run check` (валидирует и `core/`, и установку в корне). Оба должны быть зелёными.
4. **Структурные изменения** (добавить / удалить / переименовать агента или skill) — через `soul-keeper`.
5. **Таблица `core/legacy/0.1.json`** — хеши файлов релизов 0.1.x. Она нужна для миграции старых установок и не меняется.
