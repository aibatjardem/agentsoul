## Правила разработки AgentSoul

1. **Источник истины — `src/`.** `plugins/agentsoul-<локаль>/` и `.claude-plugin/marketplace.json` генерирует `npm run build`; руками их не правят.
2. **Имена агентов и skills в текстах пишутся как `{{plugin}}:<имя>`** — сборщик подставляет имя плагина локали. Голое имя в бэктиках валидатор не считает ссылкой.
3. **Бюджет хука.** `src/locales/<l>/soul/core.md` ≤ 6 500 символов, весь контекст хука ≤ 9 000 (лимит Claude Code — 10 000). Большое — в skills.
4. **Хук — только встроенные средства bash** (при старте сессии PATH может быть сломан): никаких `cat`, `sed`, `wc`, `jq`.
5. **Frontmatter агентов** — только `name`, `description` (на английском), `tools` (обязательно с `Skill`), `model: inherit`, `skills: [{{plugin}}:…]`.
6. **Версия** — одна, в `package.json`; поднимай её при каждом релизе, иначе пользователи останутся на кэше.
7. **Перед коммитом:** `npm run build && npm test && npm run check` — всё зелёное.
8. **Диск exFAT:** после клонирования на TRANSCEND исполняемость скриптов хука держится только в индексе git (`git update-index --chmod=+x`); `._*` — мусор macOS, он в `.gitignore`.
