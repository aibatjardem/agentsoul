# AgentSoul — как начать

Пошаговая инструкция для тех, кто впервые работает с Claude Code. Займёт 10–15 минут.

> Сейчас работает русский плагин `agentsoul-ru`. Языковые пакеты (TypeScript, Python, Go, Java, C#) появятся в одном из ближайших обновлений. Если включено автообновление (шаг 6), они придут сами.

---

## 1. Поставь Claude Code

Если Claude Code уже стоит, переходи к шагу 2.

**macOS / Linux** — открой терминал и выполни:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows** — открой PowerShell и выполни:

```powershell
irm https://claude.ai/install.ps1 | iex
```

> **Windows:** обязательно поставь ещё [Git for Windows](https://git-scm.com/download/win). Без него AgentSoul не загрузится, хотя сам Claude Code будет работать.

Затем запусти в терминале:

```bash
claude
```

и войди в свой аккаунт — Claude Code сам подскажет, что делать.

Подробнее об установке — на [официальной странице Claude Code](https://code.claude.com).

## 2. Поставь плагин AgentSoul

Внутри Claude Code (там, где пишешь сообщения) введи по очереди две команды:

```
/plugin marketplace add aibatjardem/agentsoul
```

```
/plugin install agentsoul-ru@agentsoul
```

Потом закрой Claude Code командой `/exit` и запусти снова (`claude`). Плагин подключается при старте.

## 3. Настрой свой проект

Это делается **один раз в каждом проекте**.

1. В терминале перейди в папку проекта:

   ```bash
   cd путь/к/проекту
   ```

   Для нового проекта сначала создай пустую папку: `mkdir my-bot && cd my-bot`.

2. Запусти Claude Code:

   ```bash
   claude
   ```

3. Введи:

   ```
   /agentsoul
   ```

   Это главное меню AgentSoul. Оно увидит, что проект ещё не настроен, и предложит настройку — соглашайся. (То же самое напрямую: `/agentsoul-ru:setup`.)

4. Отвечай на вопросы:
   - новый это проект или уже существующий — во втором случае Claude сначала посмотрит на код;
   - на каком языке проект — можно выбрать несколько;
   - какой стек — можно взять готовый профиль или ответить на вопросы по шагам;
   - как называются главные вещи в проекте — например «заказ», «клиент», «товар».

   Не знаешь, что ответить, — выбирай вариант с пометкой **«(Рекомендуется)»**.

В проекте появится папка `.soul/`:

```
.soul/
├─ stack.md        стек: языки, фреймворки, база данных, тесты
├─ glossary.md     словарь проекта
└─ local/
   └─ rules.md     твои правила
```

Сохрани её в git вместе с кодом:

```bash
git add .soul
git commit -m "AgentSoul: настройки проекта"
```

## 4. Работай

Просто пиши задачи обычными словами, например:

> Сделай Telegram-бота, который принимает заказы и сохраняет их в базу

Claude сам:

- вспомнит твой стек и термины из `.soul/`;
- задаст вопрос, если что-то неясно, — с вариантами ответа;
- напишет код вместе с тестами;
- позовёт нужных специалистов, а в конце — ревьюера.

Позвать специалиста вручную: напиши `@agent-` и выбери из подсказки, например:

```
@agent-agentsoul-ru:code-reviewer проверь, что я сделал
```

### Полезные команды

| Команда | Что делает |
|---|---|
| `/agentsoul` | **Главное меню** — если не помнишь, что запустить, начни с него |
| `/agentsoul-ru:setup` | Настроить проект |
| `/agentsoul-ru:project-initializer` | Обновить стек (например, сменил базу данных) |
| `/agentsoul-ru:glossary-initializer` | Добавить новые термины проекта |
| `/agentsoul-ru:soul` | Показать полный текст правил AgentSoul |

## 5. Свои правила

Открой файл `.soul/local/rules.md` и пиши обычным языком, как объяснял бы новому человеку в команде:

```markdown
- Тексты для пользователей — только на русском
- Перед тем как что-то удалять — спрашивай меня
- Задачи делай сам, вопросы задавай только если без них никак
```

Эти правила **сильнее всего остального** — и правил AgentSoul, и стандартных настроек Claude Code. Файлов в `.soul/local/` может быть сколько угодно.

## 6. Обновление

Включи автообновление, и дальше ничего делать не придётся:

`/plugin` → **Marketplaces** → **agentsoul** → **Auto-update**

Обновлять вручную — в обычном терминале (не внутри Claude Code):

```bash
claude plugin marketplace update agentsoul
claude plugin update agentsoul-ru@agentsoul
```

и перезапусти Claude Code.

Обновление меняет только плагин — папку `.soul/` в твоих проектах оно не трогает.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| Claude пишет, что `stack.md` не заполнен | Запусти `/agentsoul-ru:project-initializer` |
| Не видно агентов или команд `/agentsoul-ru:…` | Перезапусти Claude Code. Проверь в `/plugin`, что плагин `agentsoul-ru` включён |
| Windows: AgentSoul не загружается | Поставь [Git for Windows](https://git-scm.com/download/win) и перезапусти Claude Code |
| Советует не то, что нужно | Проверь, что в `.soul/stack.md` написана правда. Не согласен с каким-то принципом — допиши своё правило в `.soul/local/rules.md` |
| В проекте остались файлы старого AgentSoul (ставился через npm) | Запусти `/agentsoul-ru:setup` — он покажет, что удалить, и спросит подтверждение |
