## Локальные правила проекта

> Самый сильный слой: правила отсюда побеждают `.soul/*`, skills и глобальные defaults Claude Code.
> AgentSoul никогда не перезаписывает файлы в `.soul/local/`. Новый файл здесь → `npx agentsoul update`, чтобы подключить его в `CLAUDE.md`.
